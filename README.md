# Ensomi Model

Ensomi generates 4-key rhythm-game charts (osu!mania 4K) from music. It aims to
make listening to music, playing it and creating for it one activity: charts
that follow music already playing, choreography for a section a mapper
selects, practice charts for a movement a player wants to train. This
repository holds Ensomi's models with their training and evaluation, the
released Python system, the model service and the ONNX exporter; the
[V3 formulation](docs/formulation/README.md) defines the target problem.

## Released model: Ensomi R2

Ensomi R2 turns a song into an osu!mania 4K chart. Give it an audio file and a
star rating, and it writes a complete `.osz` with the chart, the audio and a
receipt of every setting used. A timing system fits a beat grid to the song, a
rows model decides where notes start, and R2 arranges the lanes, taps and long
notes. Its [model card](https://huggingface.co/sed-i/ensomi-r2) on Hugging Face
has the weights and says how to use it, what you can ask for and what has been
checked. The [R2 report](docs/research/r2_system.md) explains the project's
aims, the decisions that shaped R2 and what it cannot do yet.

![SaiGetsu: a chart generated by Ensomi R2](https://huggingface.co/sed-i/ensomi-r2/resolve/main/previews/saigetsu.png)

Yellow notes are taps and cyan notes long notes, read bottom to top. The
[gallery](https://huggingface.co/sed-i/ensomi-r2/blob/main/PREVIEWS.md) has
more songs; the examples illustrate behavior and are not a quality benchmark.

[ensomi.app](https://ensomi.app) generates a chart in the browser and the
[Ensomi app](https://github.com/ensomi-labs/ensomi) on macOS, both with the
[Ensomi runtime](https://github.com/ensomi-labs/runtime).

### Generate a chart

Install [uv](https://docs.astral.sh/uv/) and the
[Hugging Face CLI](https://huggingface.co/docs/huggingface_hub/guides/cli).
Only macOS arm64 on the CPU has been checked; on Linux with NVIDIA, use
`--extra cuda` instead of `--extra mps`.

```sh
git clone https://github.com/ensomi-labs/ensomi-model.git
cd ensomi-model
git checkout --detach r2-1.0.1
uv sync --python 3.10 --extra mps
hf download sed-i/ensomi-r2 --revision r2-1.0.1 --local-dir artifacts/hf-r2

uv run --python 3.10 --extra mps python -m ensomi_model.system.make \
  --model-dir artifacts/hf-r2 --audio /path/to/song.mp3 --star 3.5 \
  --title "Song title" --artist "Artist" --seed 0 --out artifacts/my-chart.osz
```

The card's [quick start](https://huggingface.co/sed-i/ensomi-r2#quick-start)
has the requests, timings and platform notes.

### Data provenance

The rows model and R2 were trained on 11,368 eligible ranked and loved
osu!mania 4K charts, which are not distributed here. R2 is not built to
imitate any particular mapper or artist
([evidence](docs/research/r2_data_provenance.md#mapper-and-artist-style)).
The [data provenance](docs/research/r2_data_provenance.md) report records each
stage's charts and labels as attribution, not rights clearance, and how to ask
for a correction.

## Feedback and contributing

Report a generated chart with the
[chart feedback form](https://github.com/ensomi-labs/ensomi-model/issues/new?template=chart-feedback.yml),
without audio. Ideas and questions go to
[Discussions](https://github.com/orgs/ensomi-labs/discussions), and feedback on
the mapping tools and the pattern dataset to
[beatmap-lens](https://github.com/ensomi-labs/beatmap-lens).
[`CONTRIBUTING.md`](CONTRIBUTING.md) says what happens to a report and how to
set up, test and contribute code.

## Repository map

| Path | Contents |
| --- | --- |
| `src/ensomi_model/system/` | the end-to-end system (`make`), its corpus prior, controls and arrangement loop |
| `src/ensomi_model/audio_rows/` | the timing system and the rows model, with the rows model's training and evaluation |
| `src/ensomi_model/r2/` | R2: model, training, sampling, evaluation and export |
| `src/ensomi_model/evaluation/` | corpus-referenced evaluation of generated charts |
| `src/ensomi_model/service/` | the model service, which the Ensomi app uses as its chart server ([how to run it](docs/research/r2_system.md#serve-the-app)) |
| `src/ensomi_model/export/` | the exporter of the runtime's ONNX model package ([guide](docs/guides/onnx_runtime.md)) |
| `src/ensomi_model/research/` | earlier research code, including the chart schema, exact replay and temporal layers R2 builds on |
| [`docs/research/`](docs/research/README.md) | research reports, among them R2's and its data provenance |
| [`docs/formulation/`](docs/formulation/README.md) | the V3 problem definition |
| [`docs/ecosystem.md`](docs/ecosystem.md) | where facts the Ensomi repositories share are defined, and what a change affects |
